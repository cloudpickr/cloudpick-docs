> 文書基準: 2026年8月 (2次段階評価結果反映)

## 概要

ソブリンAI（Sovereign AI）とは、特定の国が自国のデータ・言語・文化・産業コンテキストに最適化されたAIモデルとインフラを自国の技術で確保することを指します。韓国政府はグローバルAIモデルへの技術的・経済的・文化的な従属を懸念し、「AI3大強国（AI3強）への飛躍」を国政の核心目標に掲げ、独自AIファウンデーションモデルの開発と国家AIインフラの構築を並行して推進しています。

本文書では、政策推進の経緯と2026年8月現在の進捗状況、そしてエンタープライズアーキテクトが考慮すべき示唆をまとめます。

## 独自AIファウンデーションモデルプロジェクト

### 目的と規模

科学技術情報通信部と情報通信産業振興院（NIPA）が主管する「独自AIファウンデーションモデル」プロジェクトは、GPT・Geminiなどグローバルトップクラスのモデルに匹敵する国産ファウンデーションモデルを開発することを目標としています。選定された開発チームには、GPUインフラ、学習データ、事業費が集中的に支援されます。

1次補正予算基準で**GPU賃借支援予算が1,576億ウォン**規模であり（データ・人材支援は別途項目）、プロジェクト全体の予算規模は報道によって幅があり、公式に確定した数値とは言えません(段階別予算は事業費審議の過程で調整される可能性があります)。

:::note
韓国のAI技術力は2024年基準で世界6位水準と評価されており、政府は本プロジェクトを米国・中国に次ぐ「AI3強」飛躍の最初の関門と位置づけています。
:::

### 選定方式 — 段階的な競争縮小

本プロジェクトは、多数のチームを選抜した後、6か月ごとに段階評価を実施してチーム数を順次絞り込み、最終的に2チームのみを残す**トーナメント型の競争構造**として設計されています。

### 選定経緯 (2025年7月 ～ 2026年8月)

| 時点 | 経緯 |
| --- | --- |
| 2025年7月21日 | 精鋭チーム公募締切 — 計15チームが応募 |
| 2025年7月25日 | 書面評価通過10チームが確定 |
| 2025年8月 | 発表評価を経て**1次精鋭チーム5社**が最終選定 — ネイバークラウド、アップステージ、SKテレコム、NC AI、LG AI研究院 |
| 2025年12月30日 | 1次段階評価発表会（中間成果公開） |
| 2026年1月15日 | 1次段階評価結果の公式発表 — **ネイバークラウド、NC AIが脱落**、3チーム(LG AI研究院、SKテレコム、アップステージ)が生存 + 追加公募開始 |
| 2026年1月15日 | 政府、脱落分を補うための精鋭チーム1社追加公募を発表 |
| 2026年2月12日 | 追加公募受付締切(モティーフテクノロジーズ・トリリオンラボの2コンソーシアムが応募) |
| 2026年2月20日 | **モティーフテクノロジーズ**が4番目の精鋭チームとして選定・合流 |
| 2026年8月8日～11日 | **2次段階評価**実施 — LG AI研究院・SKテレコム・アップステージ・モティーフテクノロジーズの4チームが対象。グローバルベンチマーク、専門家審査、200名規模の国民評価団による評価を総合 |
| 2026年8月18日 | **2次段階評価結果発表** — **アップステージ・SKテレコム・LG AI研究院**が3次段階に進出、**モティーフテクノロジーズが脱落**。モティーフはグローバルAAII評価で47点（韓国モデルとして唯一グローバルトップ10入り）を記録したが、ユーザー評価（有用性・実用性）で相対的に低い点数を受け、最終65.8点で脱落。3次進出チームにはチーム当たり約1,000枚のB200 GPU（チーム当たり約400億ウォン、総額1,200億ウォン規模）がリース支援される |
| 2026年8月18日 | 政府、「独破模」を超え**フロンティア級AIモデル開発**への戦略再編検討を発表。既存の分散競争モデルではグローバルフロンティア企業との競争が困難と判断し、独破模とミトス級フロンティアAI開発プロジェクトを連携・統合する方案を検討中。SPC（特殊目的法人）構成または特定企業主導方式の両方がオープン状態 |

:::caution
2次段階評価の結果に基づき、モティーフテクノロジーズに対する異議申し立て・疎明手続きが進行予定であり、3次段階評価は当該手続きの完了後に開始されます。3次評価で最終2チームが選定されます。政府が検討中のフロンティアAI戦略再編の具体的方向性（独破模事業の継続可否を含む）は追って発表予定です。
:::

## 国家AIインフラ — 国家AIコンピューティングセンター

独自モデルの開発とは別に、政府はGPU供給のための国家AIコンピューティングインフラを構築しています。

- 政府は**5万枚以上のGPU確保**を目標としたロードマップを発表しており、K-LLM開発チームにGPUを賃貸形態で支援します。
- 2026年8月3日、全羅南道海南郡のソラシドデータセンターパーク敷地で**国家AIコンピューティングセンター着工式**が行われ、建設が本格化しました。1次構築規模は約1.5万枚の半導体ベースと報じられています。
- GPU機種は2026年8月時点でまだ最終確定していないと報じられており(「B200確定ではない」)、最新のAI半導体を導入する方向で検討されています。
- 政府は2026年2月「人工知能基本計画（2026〜2028）」を通じて、ソブリンAI関連政策を国家AI戦略の柱として明文化しました。

## エンタープライズアーキテクトの観点からの示唆

- **ベンダー地形の流動性**: 2次段階評価（2026年8月18日）を通過した3チーム（LG AI研究院、SKテレコム、アップステージ）が3次評価で最終2チームに絞り込まれます。さらに政府が「独破模」を超えたフロンティア級AI戦略再編を検討中のため、事業構造自体が変わる可能性もあります。特定チームの長期ロードマップにアーキテクチャを全面的に依存させるよりも、**FMを交換可能なコンポーネントとして扱うゲートウェイ・抽象化レイヤー**を設けることがリスク管理上有利です。
- **技術的優位性≠選定**: 2次評価でモティーフテクノロジーズはAAIIグローバル10位（47点）と技術力1位だったが、ユーザー評価（有用性・実用性）で低い点数を受けて脱落しました。これは政府が純粋なベンチマーク性能よりも実際のサービス品質と産業適用性をより重視する方向で評価していることを示唆しています。
- **公共・規制調達との接続**: 精鋭チームとして選定されたベンダーのモデルは、公共機関・規制産業の調達において「国産ソブリンモデル」候補として優先的に検討される可能性が高いです。公共部門を対象とする組織は、最終生存チームの動向を調達ロードマップに反映する必要があります。
- **フロンティアAI戦略の変化**: 政府は分散競争モデルの限界を認識し、SPC（特殊目的法人）等による資源集中方案を検討しています。これは今後、国産FM生態系が現在の多者競争構図から少数集中構図に再編される可能性を意味します。
- **ソブリン要件との結合**: ソブリンAI政策は[CSAP](../../security/csap/)、[網分離緩和](../../security/network-isolation/)など他の規制トラックと連動して動きます。機微データを扱うワークロードは、グローバルモデルの代わりに国内ソブリンモデルを要求される可能性を念頭に置く必要があります。
- **GPUインフラの供給時期**: 国家AIコンピューティングセンターは2026年8月時点で着工段階であり、実際のサービス提供可能時期までにはまだ時間が必要です。短期的に国産FMを導入しようとする組織は、[FM提供社比較](../fm-providers/)文書のベンダー別API・クラウド提供チャネルを通じてアクセスするのが現実的です。
- **性能ベースライン**: 政府は独自モデルの目標を「グローバルトップクラスモデルの95%以上の性能」として提示しています。導入を検討する組織はこの数値をベンチマークとしつつ、実際の業務タスクにおける性能を別途検証する必要があります。

## よくある間違い

- **最終生存チームを既成事実として前提に長期契約を締結** — 2026年8月時点で3次評価（アップステージ・SKテレコム・LG AI研究院の3チーム対象）で最終2チームが選定予定であり、さらに政府のフロンティアAI戦略再編により事業構造自体が変わる可能性もあります。特定チームのロードマップに調達を全面的に依存させることは危険です。
- **「ソブリンAI＝無条件に国産モデル」と単純化** — ソブリンAI政策は特定の機微ワークロード(公共、安全保障、規制データ)に対する代替手段の確保を目的としており、すべてのワークロードを国産モデルに切り替えることを意味するものではありません。ワークロードごとに要件を区分して判断してください。
- **国家AIコンピューティングセンターの利用可能時期を過大評価** — 2026年8月時点で着工段階であり、実際のサービス提供までにはかなりの時間を要します。短期導入計画には反映しないのが安全です。
