# CloudPick Docs

CloudPick은 클라우드의 개념과 이론을 쉽게 설명하여, 독자가 빠르게 이해하고 실무에 적용할 수 있도록 돕습니다. AWS, Azure, GCP, OCI를 중립적으로 비교합니다.

{% hint style="info" %}
모든 기술 내용은 벤더 공식 문서 또는 업계 표준 자료를 근거로 합니다. 실제 도입·운영 시에는 각 벤더의 최신 공식 문서를 함께 확인하세요.
{% endhint %}
